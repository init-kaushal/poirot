The method

How the investigation runs

Five steps, always in the same order. The first four are cold and deterministic — same cluster in, same bytes out. The fifth is optional, and says so honestly when it runs out of time.

01

Discover

Probes the cluster for a PromQL-compatible metrics backend and an OpenCost service, reached through the Kubernetes API-server proxy — no port-forward, no extra RBAC beyond what's already needed to read. Missing backends aren't an error; they're just noted as absent.

02

Collect

Pods, deployments, events, nodes, PVCs, jobs, HPAs — a point-in-time snapshot, taken with get/list/watch and nothing stronger.

03

Analyze

Four rule sets run cold over the snapshot: reliability, SLO/golden-signals, rollout risk, and cost. No network calls, no LLM — pure functions over what was collected.

04

Investigate optional

Handed only read tools — snapshot lookups, logs, the same metrics/cost queries — an LLM is turned loose per flagged object to work out probable cause, confidence, and remediation. Bounded by a tool-call, token, and wall-clock budget; it degrades to "not investigated" rather than run forever.

05

Report

A canonical report.json plus a rendered report.md. The deterministic findings are byte-identical run to run. The investigator's prose — by its nature — is not, and the report says so.

Lines of inquiry

Four deterministic rule sets

Each runs independently and degrades independently. Losing one backend never takes the others down with it.

Reliability 17 checks

Crash loops, OOM kills, unschedulable pods, missing limits/probes/PodDisruptionBudgets, floating image tags, single points of failure.

requires kubeconfig only

SLO golden signals

CPU/memory saturation against limits, restart rate, scrape-target health, readiness — pulled straight from PromQL.

requires Prometheus-compatible backend

Change rollout risk

Recent rollouts and their health, deploys stuck on observedGeneration, ReplicaSet churn — native, no GitOps tooling assumed.

requires kubeconfig only

Cost 7 checks

Rightsizing, idle workloads, over-replication, orphaned PVCs and LoadBalancers, retained Jobs, namespace spend trend.

requires nothing — estimates without OpenCost
The verdict

It never refuses to testify

Every optional piece has a documented failure mode, and none of them is "poirot exits with an error."

No API key

The investigation phase is skipped. The deterministic report still writes, with a banner explaining why.

No metrics backend

SLO analysis reports itself skipped. Reliability, change, and cost run exactly as if nothing were missing.

No OpenCost

Cost falls back to estimating from resource requests, and every figure it produces is labeled estimated, not quietly passed off as measured.

The model runs out of time

A global wall-clock budget cuts the investigation off cleanly. Whatever got enriched, stays enriched; the rest says not investigated instead of a stalled process.
